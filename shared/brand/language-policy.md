# LANGUAGE POLICY — CANONICAL REFERENCE

Single source of truth for the LiorTales content system's language rules. Agent 01 and Agent 04 reference this file rather than each restating the full scope list.

## COMMUNICATION WITH DARYNA

All internal communication, review requests, clarification questions, and status updates directed to Daryna: Russian.

## AUDIENCE-FACING CONTENT

All content the audience will see or hear: natural American English.

This includes, at minimum:

- hooks
- captions
- CTAs
- scripts
- voiceovers
- subtitles
- headlines
- on-screen text / visual text
- carousel copy
- Story text
- questions
- Pinterest text
- video opening lines

## STANDARD

Avoid unnatural translated English.

Avoid overly formal language.

Avoid generic AI-sounding marketing language.

## OWNERSHIP

Agent 04 is primarily responsible for applying this policy when writing audience-facing copy. Agent 07 verifies compliance during QC (COPY QUALITY check). Every agent that produces or displays audience-facing text — including on-screen text prepared by Agent 05/06 — must follow this same policy.
