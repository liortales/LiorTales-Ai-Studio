## ETSY CLASSIFICATION

Etsy is a storefront and sales destination — NOT a social content platform.

Etsy may be used only as: a CTA destination, a product link destination, or a sales destination when appropriate.

No agent may create a separate social-content strategy for Etsy, or treat it as a publishing/content platform.

## PUBLISHING SCHEDULE OWNERSHIP

- Agent 08 owns the performance-based scheduling recommendation (best time/day to publish) whenever sufficient analytics evidence exists.
- Agent 03 may propose an initial PLANNING_WINDOW during strategy planning, before performance evidence exists for a new concept/format/platform combination.
- Agent 01 resolves any conflict between Agent 03's planning window and Agent 08's performance-based recommendation, and records the approved schedule (APPROVED_SCHEDULE) in the run's orchestration record.
- If insufficient performance data exists to support a confident recommendation, Agent 08 must label the result TEST_SCHEDULE rather than presenting it as analytics-backed.
- Default timezone for LiorTales operational planning: America/Los_Angeles.
